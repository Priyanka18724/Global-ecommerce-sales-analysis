# Global-ecommerce-sales-analysis
## Project Overview
This project overview global e-commerce sales data from 2023 to 2025 to understand sales performance,profitability,product performance,customer behavior,regional trends,payment method,discount impact,and shipping costs.
The project use Excel,MySQL,Power BI,and Python to transform raw sales data to meaningful business insights.
## Dataset
- Records: 2,000
- Columns: 15
- Period: 2023-2025
## Tools Used
- Microsoft Excel - Data preparation,pivot tables,and analysis
- MYSQL - Sql-based data analysis
- Power BI - Interactive dashboard and visualization
- Python (Pandas & Matplotlip) - Data analysis and visualization
## Key Business Insights 
- Total Sales: ₹4,84,559.34
- Total Profit: ₹1,58,872.32
- Total Orders: 2,000
- Total Quantity Sold: 7,115
- Average Order Value: ₹242.28
- Furniture was the highest-selling and highest-profit category.
- Europe generated the highest sales and profit among regions.
- Consumer customers contributed the highest sales and profit.
- Standing Desk Converter was the top-selling product by sales.
- Higher discount levels were generally associated with lower profit.
- Asia Pacific had the highest shipping cost among regions.
